3. **Focus indicators** — `:focus-visible` class from Tailwind: `focus-visible:ring-2 focus-visible:ring-yellow-400 focus-visible:ring-offset-2 focus-visible:ring-offset-slate-900`.
4. **Icon buttons** — every icon-only button has an `aria-label` or `.sr-only` span.
5. **Color contrast** — every text/background pair >= 4.5:1 (verify via Walmart palette + WCAG rules from `cp_walmart_colors` skill).
6. **Skip link** — first focusable element in base.html: `<a href="#main" class="sr-only focus:not-sr-only ...">Skip to main content</a>`.
7. **Images** — every `<img>` has `alt=""` (decorative) or descriptive alt.
8. **Table headers** — runs_list.html table uses `<th scope="col">`.
9. **aria-live** — progress panel already has this from 03-04; verify.
10. **Keyboard reachability** — every clickable div/span becomes a `<button>` (pick cards especially).

Manual axe DevTools scan on each page after changes. Fix every reported issue.
