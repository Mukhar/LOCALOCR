  <action>
New script `benchmark_extraction.py` (top-level, next to `benchmark_easyocr.py`).

Behavior:
1. Accepts CLI args: `--video <path>` (required), `--interval <seconds>` (default 2), `--threshold <float>` (default 0.3), `--max-gap <seconds>` (default 10), `--keywords <comma-sep>` (default from `config/config.json` `match_keywords`).
2. For each of the three modes (`interval`, `scene`, `hybrid`):
   - Create a temp output dir
   - Time `extract_frames()`
   - Time `run_ocr()` on the extracted frames (use Apple Vision engine for speed and consistency across modes)
   - Time `match_text()` against the keywords
   - Collect: frame_count, extract_wall_seconds, ocr_wall_seconds, match_wall_seconds, set of unique keywords matched
3. Print a markdown table:

    | Mode | Frames | Extract | OCR | Match | Total | Unique Keywords Matched |
    |------|--------|---------|-----|-------|-------|-------------------------|
    | interval | N | X.Xs | X.Xs | X.Xs | X.Xs | {kw1, kw2, ...} |
    | scene    | N | X.Xs | X.Xs | X.Xs | X.Xs | {kw1, kw2, ...} |
    | hybrid   | N | X.Xs | X.Xs | X.Xs | X.Xs | {kw1, kw2, ...} |

4. Print a summary line: `Scene vs Interval: <ratio>x frame reduction, <lost_keywords or "no keywords lost">`.

5. **Exit-code gate for the "no keywords lost" half of EXTRACT-01** (fixes plan-check WARNING 6):

        interval_kws = set(results['interval']['unique_matched_keywords'])
        scene_kws    = set(results['scene']['unique_matched_keywords'])
        lost = interval_kws - scene_kws
        if lost:
            print(f"FAIL: scene mode lost keywords vs interval: {sorted(lost)}",
                  file=sys.stderr)
            sys.exit(2)
        print("OK: no keywords lost")

    Exit 0 on success, exit 2 on any lost keyword. `benchmark_extraction.py`
    is thereby usable as a pre-commit / CI gate, not just a print-and-hope
    utility.

Cleanup: delete the temp output dirs after benchmark (unless `--keep-output`).

**Zero duplication:** import `extract_frames`, `run_ocr`, `match_text` from `src/`. Do NOT copy any logic.
